# Дизайн

Текущий интерфейс использует бумагу, чёрную печать и ультрамарин. Prata и Oswald задают характер заголовков, Golos Text — элементы управления. Тёмная тема и переключатели языка удалены по выбранной концепции. Язык определяется по статье, межъязыковой поиск включается автоматически.

Полная спецификация: [столкновение энциклопедий](collision-design.md).
