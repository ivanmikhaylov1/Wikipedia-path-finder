Важное расхождение с заданием: реальный main уже использует Unbounded, но его CSS
ещё содержит прямо запрещённые в текущем задании #ad3028 и #252820. Поэтому шрифты
и геометрическая шкала взяты из main, а палитра приведена к явно указанным пользователем
терракотовым и кремово-угольным значениям. Это изменение описано, а не выдано за токены main.
Все цвета сцены, состояний и карточек читаются из CSS-переменных; тема обновляет canvas.

Тёплая матовая поверхность, простая типографика, тонкие линии и прямые края сохраняют
характер проекта. Единственный активный визуальный момент — поиск. Убраны тяжёлый
реквизит и дополнительное постоянное движение: в idle/done RAF останавливается.

Алгоритм BFS main, LinkSource, батчи 50, балансировка, бюджеты, CSR, langlinks и PWA
сохранены. Исключения, прямо запрошенные пользователем: изоляция кэша по лимиту и
вынос предварительной цепочки первых ссылок в feat/first-link-preview. Сцена получает
только реальные progress/found/notFound; задержки 2400/700/1800мс относятся к визуалу.

Прототип krasnaya-nit.html отсутствует в рабочем пространстве. Сверка выполнена по
письменной спецификации, сравнение с самим HTML-прототипом невозможно.

## P1: обещания поиска

Hero: «Найдите цепочку ссылок между двумя статьями». Лид: «Поиск идёт навстречу с обеих сторон и ограничен лимитами: путь есть не всегда, найденный не обязательно кратчайший». Результат: «Найден путь из N шагов». Нет обещания достижимости любой пары. В пределах раздела шаг — гиперссылка, между языковыми версиями — межъязыковой переход с текстовой подписью в списке и пунктиром на сцене. Пояснение раздела встроено рядом с переключателем; модального окна нет. OG, description и manifest описывают ограниченный поиск. Типографика, палитра, токены, BFS и LinkSource не меняются.
