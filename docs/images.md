# Изображения

Актуальные файлы, точные prompts, источники шрифтов и условия генератора: [collision-assets.md](collision-assets.md). Концепты сохранены в WebP в [concepts](concepts); это иллюстративные макеты, а не проверенные маршруты Википедии.

Браузерные снимки создаёт `npm run test:e2e`; они сохраняются в `test-results/` и прикладываются к CI-артефактам. Снимки не отслеживаются в Git. Иконки воспроизводятся командой `node scripts/prepare-icons.mjs`.
