# Изображения

Все текущие изображения — воспроизводимые процедурные аналоги прежних сгенерированных
изображений. Прежние оригиналы в другой палитре заменены, внешние исходники не нужны.
`npm run prepare:images` использует sharp и установленный Playwright Chromium.

| Файл | Размер | Назначение |
|---|---|---|
| knowledge-map.webp | 2400×1400 | Статичная карта и noscript |
| grain.webp | 512×512 | Тёплое зерно, низкая непрозрачность, reduced-data отключает |
| empty.webp | 800×500 | Прозрачная иллюстрация пустого состояния |
| og.webp | 1200×630 | «Переходы», настоящий локальный Unbounded 600 |
| favicon.svg / icon.svg | 512×512 | Два кремовых узла и терракотовая нить |
| apple-touch-icon.png | 180×180 | iOS |
| icon-192.png / icon-512.png | 192 / 512 | Manifest |

Палитра: #1e2327, #efe6d6, #e8703f. Все WebP ≤150000 байт; точные размеры —
[image-sizes.json](image-sizes.json). Alt заданы в компонентах и OG-метаданных;
декоративная текстура не озвучивается. Без людей, логотипов или сторонних акцентов.

Четыре ключевых снимка создаёт `node scripts/capture-stage.mjs` при запущенном production
preview с base=/; исходники API замоканы внутри скрипта. Полная матрица 360/768/1280,
обе темы и reduced-motion создаётся E2E в test-results и загружается CI-артефактом.
